## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## SMTP setup

Create a local environment file from `.env.example` and fill in your SMTP provider credentials:

```bash
cp .env.example .env.local
```

Required values:

- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASS`
- `SMTP_FROM`

## Playwright tests

Install dependencies and run the end-to-end smoke tests:

```bash
npm install
npx playwright install
npm run test:e2e
```

The tests validate the homepage, auth pages, footer contact email, and the new `/api/email` route validation.
